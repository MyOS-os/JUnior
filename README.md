# Язык программирования JUnior

JUnior — учебный язык программирования и проект для практики построения
лексера, парсера и интерпретатора. Язык задуман как универсальный, а реализации
планируются на **Java**, **C** и **C++**.
В репозитории лежит стартовая документация и правила оформления.

## Цели
- Простой синтаксис, который легко парсить.
- Единая спецификация для реализаций на Java/C/C++.
- Пошаговое развитие: интерпретатор → байткод → (опционально) нативная компиляция.

## Структура проекта
- `docs/spec.md` — спецификация языка.
- `docs/roadmap.md` — план работ по этапам.
- `.editorconfig` — базовые правила форматирования.

## Как работать с репозиторием
1. Опишите грамматику и правила в `docs/spec.md`.
2. Начните с реализации лексера и парсера на выбранном языке.
3. Соберите минимальный интерпретатор.

## Пример (черновик)
```junior
let x = 10;
print(x + 5);
```
